
Running the code


To run the code open the code folder and paste each from script 1 - 3 in google collab

Make sure to select runtime as nvidia T4 as gpu in the runtime of google collab

after executing the first cell in script 1 make sure to restart runtime to refresh the vllm model

then upload kv cache data in collab file and execute script 2 

then upload models.pkl and execute script 3 , it should give you a detailed output of the prefetching model and compares it with the current models

Output
 
The out graphs are given in the graphs_results folder and the report is attached which is a compilation of the results and interpreted them
